# 📐 VisuMath — 看图理解数学

帮助 5~8 年级(小学高年级到初中)、对数学没感觉、脑子里建立不起几何画面的学生**真正看懂数学**。学生输入题目(打字或拍照),AI 老师给出**引导式讲解**(不直接丢答案)、**几何图**、**生活里的例子**,并能把要点存成**闪卡**用间隔重复巩固。

技术栈:React + Vite + TypeScript(前端)+ Express + Claude API(后端)。

> 本仓库按分阶段路线图开发,完整设计见计划文档。**当前已完成 Phase 1(引导式讲解)、Phase 2(动态可拖动几何)、Phase 3(真实生活配图)、Phase 4(家长账号 + 孩子档案 + 防沉迷/合规)。**

## 已实现

- **讲解模式**:打字或**拍照/传图**输入题目 → Claude(`claude-sonnet-4-6`)生成:
  - **引导式分步讲解**:每步先给启发性提示,学生想不出来再看解法;最终答案最后揭示,也可"直接看完整解答"(规避"答案机器"定位)。
  - **🆕 动态可拖动几何**:常见图形(三角形/多边形/圆/角)渲染成**可拖动顶点**的图,**边长、面积、角度实时跟着变**(GeoGebra 式)。所有测量值由前端纯函数计算(安全、可测),AI 只给几何数据。
  - **几何图(SVG)**:复杂图形的静态回退,服务端 + 客户端**双重消毒**,杜绝脚本注入。
  - **生活里的例子 + 🆕 真实场景配图**:把抽象概念变成熟悉画面。配图用图像 API 生成(**插画风、不含写实儿童**),**按概念缓存**省钱;没有图像密钥时优雅降级为纯文字例子。
  - **建议闪卡**:一键存入「AI 讲解」卡组(动态图、配图一并保存)。
- **复习模式**:保留 SM-2 间隔重复;复习时卡片可显示**可拖动几何图**、图解与生活例子。卡组**按孩子档案隔离**。
- **🆕 家长账号 + 孩子档案 + 防沉迷/合规**:
  - 家长邮箱注册/登录(bcrypt + httpOnly 会话 cookie);可建多个孩子档案(生日/年级/PIN/**每日使用上限**)。
  - **监护人同意**:创建档案需勾选同意;**不满 14 岁按敏感信息处理**(对齐 PIPL);家长可**导出/删除**孩子全部数据。
  - **未成年人模式/防沉迷**:进入后按档案执行**每日次数上限**(服务端拦截)、**护眼休息提醒**(每 20 分钟);**退出需家长密码**。
  - 游客可照常使用(不采集账号数据);账号层为附加能力。
- **安全后端代理**:`ANTHROPIC_API_KEY` 只在服务器,浏览器只访问同源 `/api`。结构化输出(Zod)、提示缓存、统一中文错误信封。

> 持久化目前用**轻量文件存储**(`server/db.ts`,仓储模式封装),便于在本环境零依赖运行;接口与 Prisma 等价,后续可无痛替换为 SQLite/Postgres。

## 快速开始

```bash
npm install
cp .env.example .env      # 填入 ANTHROPIC_API_KEY
npm run dev               # 同时启动 Vite(5173)和 API(8787)
```

打开终端里打印的本地地址。讲解功能需要联网访问 `api.anthropic.com`。

## 脚本

| 命令              | 说明                                   |
| ----------------- | -------------------------------------- |
| `npm run dev`     | 同时启动前端(Vite)与后端(API)      |
| `npm run build`   | 类型检查 + 生产构建                     |
| `npm start`       | 生产模式(同一进程服务 `dist/` + API) |
| `npm test`        | 运行单元测试(Vitest,无需联网)       |

## 项目结构

```
server/
  index.ts        Express:/api/explain + /api/image + 账号路由 + 生产静态托管
  claude.ts       Claude 集成(结构化输出 + 缓存 + 识图 + 错误映射)
  images.ts       真实配图生成(插画风/排除写实儿童 + 按概念磁盘缓存 + 优雅降级)
  accounts.ts     账号/孩子档案路由(注册/登录/档案 CRUD/导出/用量)
  auth.ts         密码哈希、会话 cookie、鉴权中间件
  db.ts           文件存储 + 仓储 API(可替换为 Prisma/Postgres)
  usage.ts        每日上限 / 年龄 / 用量统计(纯函数)
  prompt.ts       中文系统提示(CRA / 引导式 / 动态几何 / SVG 安全规范)
  schema.ts       Zod 结构化输出 schema
  sanitizeSvg.ts  服务端 SVG 消毒
src/
  api.ts          前端调用 /api/explain
  imageUtils.ts   上传前图片缩放
  geometry.ts     几何测量纯函数(距离/面积/角度,含测试)
  components/
    ExplainView.tsx     讲解模式 UI(引导式揭示 + 存卡)
    DynamicGeometry.tsx 可拖动几何图(顶点拖动,测量实时更新)
    SvgDiagram.tsx      客户端 SVG 再消毒后渲染(复杂图回退)
    DeckList / StudySession / DeckEditor   复习模式
  srs.ts          SM-2 间隔重复(含测试)
```
