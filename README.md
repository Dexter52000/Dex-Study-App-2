# 红黑记录与分析器 (Red/Black Recorder & Analyzer)

一个**诚实**的红黑(轮盘/百家乐红黑等)历史记录与统计工具。

## 怎么用

直接用浏览器(手机或电脑)打开 `index.html` 即可,无需安装、无需联网。

- 点 **红 / 黑** 按钮记录每一局结果,或把历史文本粘贴进去批量导入
- 实时显示真实统计:红黑比例、最长连续段、切换次数
- 给出"下一局预测"——可切换不同方式
- 数据只存在你自己的浏览器本地,不上传任何地方

## 重要说明(必须读)

这个软件**不能、也不假装能**预测下一局,原因是数学事实:

- 红黑/轮盘每一局都是**独立事件**,上一局结果不影响下一局
- 历史里"连开 8 把红"之后,下一把开黑的概率和第一把完全一样(约 50%)
- 这个错误直觉叫**赌徒谬误 (Gambler's Fallacy)**,是赌场最希望玩家相信的东西
- 所有合法红黑游戏都有**庄家优势 (house edge)**,长期期望对玩家为负

因此软件里的"预测"被**透明地标注为随机猜测**,置信度始终 ≈ 50%。
它的真正价值是帮你**亲眼看清"规律"并不存在**,避免被自己或赌场骗。

赌场放出"历史开奖板"本身就是一种心理诱导设计——详见 App 内说明。
